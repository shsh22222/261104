# ココロ寄席（こころよせ）

> **頭の中のネガティブなセリフは、妖怪のボケ。あなたはツッコミ担当。**

認知行動療法（CBT）の技法を「寄席の演目」に仕立てた、スマホ向けのWebアプリです。
自動思考を妖怪にしゃべらせ、ツッコミ（ソクラテス式質問）で言い直し、最後はふたりで漫才として上演します。

設計にあたっては、10人の専門家（臨床心理士、精神科医、ゲームデザイナー、漫才作家、民俗学者、神経科学者、行動経済学者、即興演劇の演出家、UXデザイナー、当事者のピアサポーター）の視点で、水平思考による発散 → 論争 → 収束を行いました。議論の全記録は [`docs/EXPERT_DEBATE.md`](docs/EXPERT_DEBATE.md) にあります。

第二回の会議（[`docs/EXPERT_DEBATE_2.md`](docs/EXPERT_DEBATE_2.md)）では、マインドフルネス講師と睡眠専門医をゲストに加え、**はっきりした理由のない不安**や**勝手に流れつづける思考**に向けた演目「ながめ席」を設計しました。

### ながめ席 ― ツッコまずに、ただ眺める

| 演目 | 中身 | もとにした考え方 |
|---|---|---|
| **はっ（気づき）** | 考えにのまれていたと気づいたら1タップ。鈴の音。「気づけたら、それで一本」 | メタ認知的な気づき、脱中心化 |
| **灯籠ながし** | 浮かんだ考えに一言ラベル（心配・反省会・未来…）をつけ、灯籠にのせて夜の川に流す。つかんでしまったら、またそっと流す | ACT「流れに葉を浮かべる」、ラベリング |
| **間（ま）をはかる** | ねこがネズミの穴を見張るように次の考えを待ち、来たらタップ。考えと考えのあいだの「間」に気づく（待っている間は時間を表示しない） | 考える自分を眺める練習、注意の訓練 |
| **ハラに灯す** | 顔 → 視界 → 音 → 手のひら → おへその下へ、注意を外から内へ下ろす。頭のまわりの煙がだんだん薄くなる。音声ガイドで目を閉じても進められる。「外の感覚だけ」モードあり | マインドフルネス、体の感覚への注意 |
| **下足札** | 心配を下足番に預けて札を受け取り、決めた時間（今夜・明日の朝など）に引き取る。まだ気になれば漫才のネタや行動おみくじへ | メタ認知療法の「心配の先送り」 |

新しい妖怪は「オシャベリぬらりひょん」（思考との一体化）と「モヤモヤ煙々羅」（正体のない不安）。妖怪漫才の鑑定で「なんとなく」「ずっと考えてしまう」などの言葉を見つけると、ながめ席をおすすめします。

エックハルト・トールやネドじゅんが紹介している「考えと自分を同一視しない」「頭のおしゃべりから、いまの体の感覚に戻る」という考え方も参考にしています。特別な体験や、不安が消えることは約束しません。

### いままでにない仕掛け

- **ボケ＝自動思考、ツッコミ＝反証**。現実からズレた考えを「ボケ」と見立て、自分がツッコミ側に回る。
- **12の妖怪**。サトリ（心の読みすぎ）、くだん（先読みの誤り）、大ナマズ（破局視）、おばりよん（個人化）など、伝承の性質が認知の歪みとぴったり重なる妖怪を元にした、オリジナルのキャラクター。
- **退治しない**。漫才を重ねると妖怪となかよくなり、「あなたを守ろうとしていた本音」を話してくれる。
- **妖怪ボイス**。自動思考を、妖怪の声・ヘリウム声・スローモーションで読み上げる（Web Speech API）。
- **上演**。拍子木とともに定式幕が開き、ハリセン（効果音と振動つき）でツッコミを入れ、最後は大入り。
- **3つの「予想 vs 実際」**。信じ度の前後、くだんの的中率、おみくじの楽しさ予想と実際。
- **凶＝今日（きょう）は休め**。休むことも、立派な行動。

### 安全のための設計

- 「死にたい」「消えたい」などの言葉に気づくと、やさしく立ち止まり、相談先を示し、効果音やハリセンを止めた**静かなモード**に切り替えます（書くこと自体は止めません）。
- 画面上部の「つらい時」と番組の「仲入り」から、いつでも休憩所を開けます。
- 連続記録（ストリーク）・ガチャ・課金・ランキングはありません。
- 記録はすべて端末内（ブラウザの localStorage）にだけ保存され、外部へは送信されません。書き出し・読み込み・全削除ができます。
- **このアプリは医療の代わりではありません。** つらさが続くときは、医療機関や相談窓口を頼ってください。

## 動かし方

ビルドは不要です。静的ファイルをそのまま配信するだけで動きます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください（スマホの幅で見るのがおすすめです）。

### GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にし、このアプリがあるブランチと `/ (root)` を選ぶ
3. 表示された URL をスマホで開き、「ホーム画面に追加」すると、アプリのように全画面で使えます（PWA・オフライン対応）

### 1ファイル版をつくる

CSS と JS を埋め込んだ1ファイル版（PWA用のタグなし）を書き出せます。

```bash
node tools/build-single.mjs dist/kokoro-yose.html
```

## ファイル構成

```
index.html              画面の骨組み（ヘッダー・タブ・各ルート）
css/style.css           見た目（定式幕・提灯・めくり・舞台）
js/data.js              妖怪14体、ツッコミ13種、ながめ席、おみくじ、相談先などのデータ
js/art.js               妖怪・ツッコミ担当・マイク・おみくじ箱・ねこ・灯籠などの SVG
js/nagame.js            ながめ席（気づき・灯籠ながし・間をはかる・ハラに灯す・下足札）
js/app.js               画面、ネタ作りの流れ、上演、効果音と声、保存
manifest.webmanifest    PWA の設定
sw.js                   オフライン用のサービスワーカー
icons/                  アプリアイコン
tools/build-single.mjs  1ファイル版のビルド
docs/EXPERT_DEBATE.md   10人の専門家による設計会議録
docs/EXPERT_DEBATE_2.md 第二回：ぼんやり不安と止まらない思考（ながめ席）
```

使っている技術は素の HTML / CSS / JavaScript のみで、外部のライブラリはありません（フォントのみ Google Fonts の Potta One と Zen Maru Gothic）。
効果音は Web Audio API でその場で合成し、読み上げは端末の日本語音声（Web Speech API）を使います。
