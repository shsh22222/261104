# ココロ寄席（こころよせ）

> **頭の中のネガティブなセリフは、妖怪のボケ。あなたはツッコミ担当。**

認知行動療法（CBT）の技法を「寄席の演目」に仕立てた、スマホ向けのWebアプリです。
自動思考を妖怪にしゃべらせ、ツッコミ（ソクラテス式質問）で言い直し、最後はふたりで漫才として上演します。

設計にあたっては、10人の専門家（臨床心理士、精神科医、ゲームデザイナー、漫才作家、民俗学者、神経科学者、行動経済学者、即興演劇の演出家、UXデザイナー、当事者のピアサポーター）の視点で、水平思考による発散 → 論争 → 収束を行いました。議論の全記録は [`docs/EXPERT_DEBATE.md`](docs/EXPERT_DEBATE.md) にあります。

第二回の会議（[`docs/EXPERT_DEBATE_2.md`](docs/EXPERT_DEBATE_2.md)）では、マインドフルネス講師と睡眠専門医をゲストに加え、**はっきりした理由のない不安**や**勝手に流れつづける思考**に向けた演目「ながめ席」を設計しました。

第三回の会議（[`docs/EXPERT_DEBATE_3.md`](docs/EXPERT_DEBATE_3.md)）では、横断のプロダクトデザイナーを進行役に、落語家・ユーモア研究者・スキーマ療法家・放送作家を加えて、アプリ全体の完成度を上げました。核になったのは「**出来事とつらさは本物。頭の中のセリフはフィクション（脚色つき）**」という考え方です。

### 第三回で加わったもの

- **持ちネタ集 96本**：認知の歪み12（妖怪）× 生活の場面8 の見本の漫才。それぞれに、考えの奥にある思い（ジュディス・ベックの中核信念の3分類：無力・愛されない・価値がない）をやわらかい言葉でタグづけ。ネタ表（12×8のマス目）と、場面・妖怪・奥にある思いで絞りこめる一覧。上演を観るか、ボケだけを借りて自分の漫才を作れる。
- **フィクション・テロップ**：高座で自動思考に「※イメージです」「※個人の感想です」などのテロップを貼れる。上演の最後には「※この漫才はフィクションです。…ただし、あなたのしんどさは本物です。」
- **どっちの席？**：ホームの最初に「いま、頭の中は？」と聞き、ツッコむ席（妖怪漫才）とながめる席（ながめ席）に振り分ける。
- **ツッコミの言い回し3パターン**（「エスパーか！」「いつから心読めるようになってん！」…）。質問の中身は固定。
- **上演のオート再生**、**昇進披露口上**、**楽屋日誌**（この7日間のふりかえり。比べない）、**ボケの奥にあるもの**の記録と集計、**文字の大きさ**、**記録のファイル保存と読み込み**。

### ながめ席 ― ツッコまずに、ただ眺める

演目は四つの棚に分かれています。「いまの感じ」を選ぶと、合う2演目をつないだ**おまかせ**（寝る前は**おやすみ席**）で、選ばずに始められます。

| 棚 | 演目 | 中身 | もとにした考え方 |
|---|---|---|---|
| — | **はっ（気づき）** | 考えにのまれていたと気づいたら1タップ。鈴の音。「気づけたら、それで一本」 | メタ認知的な気づき、脱中心化 |
| 流す | **灯籠ながし** | 浮かんだ考えに一言ラベル（心配・反省会・未来…）をつけ、灯籠にのせて夜の川に流す。つかんでしまったら、またそっと流す | ACT「流れに葉を浮かべる」、ラベリング |
| 注意を育てる | **間（ま）をはかる** | ねこがネズミの穴を見張るように次の考えを待ち、来たらタップ。考えと考えのあいだの「間」に気づく（待っている間は時間を表示しない） | 考える自分を眺める練習、注意の訓練 |
| 体に戻る | **ハラに灯す** | 顔 → 視界 → 音 → 手のひら → おへその下へ、注意を外から内へ下ろす。頭のまわりの煙がだんだん薄くなる。音声ガイドで目を閉じても進められる。「外の感覚だけ」モードあり | マインドフルネス、体の感覚への注意 |
| 流す | **下足札** | 心配を下足番に預けて札を受け取り、決めた時間（今夜・明日の朝など）に引き取る。まだ気になれば漫才のネタや行動おみくじへ | メタ認知療法の「心配の先送り」 |
| 体に戻る | **一服** | お茶か水を一杯。器の重さ、香り、ひとくち、のどを通る感じ、余韻を順に味わう。飲みものがなければ手のお椀で「見立て」 | マインドフルネス（飲む瞑想）、茶の湯 |
| 体に戻る | **ぎゅっとふわっ** | 手・肩・顔・足・全身を、7割の力で5秒ぎゅっ、10秒ふわっ | 漸進的筋弛緩法 |
| 注意を育てる | **お囃子の聞き分け** | 太鼓・鉦・三味線・笛（すべてアプリ内で合成）を左右に鳴らし、一つずつ聞き分け、切りかえ、全部をいっしょに聞く | メタ認知療法の注意訓練（ATT） |
| 息といのち | **インナーボディ** | 手 → 腕 → 足 → 胴体 → 全身の「生きている感じ」。最後は内側に根をおろしたまま目を開ける | エックハルト・トールのインナーボディを参考にしたアレンジ |
| 息といのち | **今ここ呼吸** | 吸うとき「いま」、吐くとき「ここ」。10呼吸。それたら「もどった」をタップして、戻れた回数を数える | ネドじゅんの今ここ呼吸を参考にしたアレンジ、数息観 |
| 息といのち | **エレベーター呼吸** | 吐く息ごとに意識のエレベーターが一階ずつ下りる（頭 → のど → 胸 → みぞおち → おなか → ハラ）。ハラ階で3呼吸とどまる | ネドじゅんのエレベーター呼吸を参考にしたアレンジ |

新しい妖怪は「オシャベリぬらりひょん」（思考との一体化）と「モヤモヤ煙々羅」（正体のない不安）。妖怪漫才の鑑定で「なんとなく」「ずっと考えてしまう」などの言葉を見つけると、ながめ席をおすすめします。

エックハルト・トールやネドじゅんが紹介している「考えと自分を同一視しない」「頭のおしゃべりから、いまの体の感覚に戻る」という考え方も参考にしています。特別な体験や、不安が消えることは約束しません。

### いままでにない仕掛け

- **ボケ＝自動思考、ツッコミ＝反証**。現実からズレた考えを「ボケ」と見立て、自分がツッコミ側に回る。
- **12の妖怪**。サトリ（心の読みすぎ）、くだん（先読みの誤り）、大ナマズ（破局視）、おばりよん（個人化）など、伝承の性質が認知の歪みとぴったり重なる妖怪を元にした、オリジナルのキャラクター。
- **退治しない**。漫才を重ねると妖怪となかよくなり、「あなたを守ろうとしていた本音」を話してくれる。
- **妖怪ボイス**。自動思考を、妖怪の声・ヘリウム声・スローモーションで読み上げる（Web Speech API）。
- **上演**。拍子木とともに定式幕が開き、ハリセン（効果音と振動つき）でツッコミを入れ、最後は大入り。
- **「前」と「後」を並べる**。漫才の信じ度、ながめ席のざわざわ度、おみくじの楽しさ予想と実際。
- **凶＝今日（きょう）は休め**。休むことも、立派な行動。

### 安全のための設計

- 「死にたい」「消えたい」などの言葉に気づくと、やさしく立ち止まり、相談先を示し、効果音やハリセンを止めた**静かなモード**に切り替えます（書くこと自体は止めません）。
- 画面上部の「つらい時」と番組の「仲入り」から、いつでも休憩所を開けます。
- 連続記録（ストリーク）・ガチャ・課金・ランキングはありません。
- 記録はすべて端末内（ブラウザの localStorage）にだけ保存され、外部へは送信されません。書き出し・読み込み・全削除ができます。
- **このアプリは医療の代わりではありません。** つらさが続くときは、医療機関や相談窓口を頼ってください。

## 動かし方

ビルドは不要です。静的ファイルをそのまま配信するだけで動きます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください（スマホの幅で見るのがおすすめです）。

### GitHub Pages で公開する

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」にし、このアプリがあるブランチと `/ (root)` を選ぶ
3. 表示された URL をスマホで開き、「ホーム画面に追加」すると、アプリのように全画面で使えます（PWA・オフライン対応）

### 1ファイル版をつくる

CSS と JS を埋め込んだ1ファイル版（PWA用のタグなし）を書き出せます。

```bash
node tools/build-single.mjs dist/kokoro-yose.html
```
