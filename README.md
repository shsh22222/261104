# 勝ち筋ラボ

架電から受注までの信頼獲得を、**商談記録 → 勝ち筋の仮説 → 一本のストーリー → 練習** の順で回すチーム用のアプリ。

「11/1資料を拝見して｜全体の論点（たたき台）」（全11ページ）を読んだうえで、立場の違う10人の専門家の視点を立てて議論し、その合意から設計した。議論の全文は [docs/10人の議論.md](docs/10人の議論.md)。参加者は実在の人物ではなく、視点を分けるための仮想のペルソナ。

- 公開版（Claudeのアーティファクト、非公開・共有は Share メニューから）：https://claude.ai/artifact/GdRNwD31kuyy4fuijjjSbG
- ブラウザで直接開く版：[dist/kachisuji-lab.html](dist/kachisuji-lab.html)（この端末だけに保存。AIは「プロンプトをコピー」でClaudeに貼って使う）

## なぜこのアプリか（議論の結論）

| 資料が示す課題 | 議論での指摘 | アプリでの答え |
|---|---|---|
| 架電12,504件 → アポ46件 → 受注0件（p.2） | どこで止まったかの記録がない。仕組み化の前に記録 | 商談記録と「信頼の指標」（段階ごとの件数、止まった理由） |
| 柳沼さんが1月以降に離れる（p.10） | 46件の振り返りが最も期限の厳しい作業 | 7つの質問に固定した振り返り入力と、46件の進み具合・期限の表示 |
| 勝った型がまだない（p.4） | 誰に・何を・どの入口でを、記録から探す | 入口・信頼の場・規模・テーマごとの2回目到達率と、AIによる勝ち筋の仮説 |
| 1対多の信頼の場（p.6） | 11/24ウェビナーの成果は後の72時間で決まる | 次の一手と期日をホームに並べ、期限切れを目立たせる |
| AIは見立ての下準備（p.7） | 断定せず質問で。人が確かめてから使う | 商談前ブリーフ（仮説は確かめる質問つき、根拠をすべて確かめると「確認済み」） |
| noteを核にした一本のストーリー（p.8） | 各フェーズで同じ話をしているかを確かめる手段が要る | 連載×フェーズのマトリクスと、AIによる「同じ話か」の確かめ |
| 人事の社内説明資料（p.9） | 人事は社内を説得する方に時間を使う | 社内説明の1枚（記録にない数字は【要確認】、講師の確認つき） |
| インターンは入れ替わる（p.3） | 練習の相手を人が毎回務められない | AIの人事とロールプレイ。記録に出た質問・断られた理由を相手に持たせ、4つの観点で講評 |

## 画面

| 画面 | できること |
|---|---|
| ホーム | 期限（ウェビナー・振り返り・1月）、これまでの数字、信頼の指標と目標（仮置き）、次の一手、止まった理由、どこで勝てそうか、勝ち筋の仮説 |
| 商談記録 | 記録する（必須は会社名・段階・次の一手）、振り返りを記録（46件）、検索・絞り込み、CSV書き出し |
| ブリーフ | 商談前ブリーフ、社内説明の1枚 |
| ストーリー | 連載ごとの「核の視点」と、架電〜導入後のトーク。下書き → 確認済み |
| 練習 | AIの人事とロールプレイ、講評、練習の記録（人ごとの回数と見立ての平均） |
| 議論と設計 | 10人の要点、原則、やらないこと、機能の順番、設定（期限・目標値） |

## データとAIの扱い

- **Claudeのアーティファクトとして開いた場合**：記録はアプリの共有データに入り、アプリを開ける人の間で共有される。AIは開いた人自身のClaudeで動く（最初の利用時に許可を求められる）。
- **ブラウザで直接開いた場合**：記録はその端末のブラウザだけに残る。AIの代わりに「プロンプトをコピー」でClaudeに貼れば同じ下書きができる。
- 記録に個人名は入れない（役職まで）。連載の題材の作品の画像や台詞は使わず、考え方を使う。
- AIの出力はすべて「下書き」から始まり、人が確かめて「確認済み」にする。誰が確かめたかが残る。お客様への自動送信はしない。
- 目標値（信頼の場→個別相談20%、個別相談→2回目40%、2回目→提案50%、提案→受注30%）は仮置き。「議論と設計」の設定で変えられる。

## 開発

```bash
python3 tools/build_standalone.py   # app/ の本文を包んで dist/ に1枚のHTMLをつくる
node tools/smoke_test.js            # Playwrightで、端末保存モードとClaude模擬モードを確かめる
```

- `app/kachisuji-lab.html`：本体（Claudeのアーティファクトとして公開する本文。`<!doctype>`などは公開時に付く）
- `dist/kachisuji-lab.html`：ブラウザで直接開ける版（ビルドで生成）
- `docs/10人の議論.md`：議論の記録
- 外部ライブラリなし。フォントは Google Fonts（BIZ UDPGothic、Zen Kaku Gothic New、IBM Plex Mono）。

## アプリでは解けないこと

- 仕組みの持ち主を誰にするか（アプリは確認と差し替えを軽くするが、持ち主の代わりにはならない）
- 大企業か中堅か（記録が20件ほどたまったら、規模別の2回目到達率で判断する）
- アイドマ様の役割を「ウェビナーへの誘導」に絞るか（入口別の比較を判断材料にする）
