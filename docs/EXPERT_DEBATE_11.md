# ココロ寄席 第十一回設計会議 ― 幕切れは、新しいセリフで

> 第十一回のきっかけは、ユーザーのこの声です。
> 「『あなたのしんどさは本物です』は、いらないかな。認知が変わったのに、しんどさの感覚に戻ってしまうから」
>
> この一文は外しました（上演の最後は「言い直したセリフは、いつでも持ち歩けます。」に）。
> 会議では、この声を手がかりに、アプリ全体の「引き戻し」を水平思考で洗い直しました。
> 登場人物は、役割を明確にするための**架空の人物**です。

## 第0幕 引き戻しの棚卸し

- **言野（コピーライター）**: ことばは、書いてある内容より先に、**呼び起こす**ものがあります。「しんどさは本物です」と言われた瞬間、人はしんどさを探しに行く。励ますつもりの一文が、せっかく軽くなった心を、元の場所に連れ戻してしまう。
- **旅路（サービスデザイン）**: アプリ全体を見ると、同じ形が他にもあります。

| 場面 | いま起きていること |
|---|---|
| 漫才の終演後 | 「**古いセリフ**を、いまどれくらい信じてる？」「**不安**の強さは？」と聞く |
| ながめ席の終わり | 「いまの**ざわざわ度**は？」 |
| 笑い噺の終わり | 「この出来事、いまの**重さ**は？」 |
| ネタ帳 | 一覧の主役が、**古いボケ**の大きな文字 |
| もう一度上演 | **ボケ**から始まる |

- **峰尾（行動経済学）**: 人は体験を、**いちばん強かった瞬間と、終わりの瞬間**で覚えます（ピーク・エンドの法則）。いまのアプリは、いちばんいいところ（言い直し・大入り）で盛り上げたあと、最後に**元の感覚を測り直して**終わっている。記憶に残る終わりが「不安の強さ」なんです。

## 第1幕 発散

### 1. 測るのは、古いセリフではなく、新しいセリフ
- **刻（記憶）**: 「古いセリフをどれくらい信じてる？」は、古いセリフを**もう一度思い出させる**問いです。思い出すたびに、記憶は強くなる。測るなら、**新しいセリフ（オチ）が、どれくらいしっくりくるか**。数字が上がっていく測り方なら、測るたびに新しい見方が強くなります。
- **言野**: 気分も、「不安の強さは？」ではなく「**いまの気分に名前をつけるなら？**」。ほっとした・すっきり・ふつう・まだもやもや。名前の候補が、前を向いている。

### 2. 幕切れは、オチで終わる
- **幕田（演出家）**: 舞台は、いちばんいいセリフで幕を下ろします。カーテンコールで、**オチをもう一度、大きく**。記録の質問は、そのあとに小さく。あるいは、なくてもいい。
- **峰尾**: 終演画面の主役を「数字の変化」から「**あなたのオチ**」に。数字は小さな添えもの。

### 3. 天丼 ― 何度も来るボケは、持ちネタになる
- **幕田**: お笑いには「**天丼**」があります。同じボケを何度もくり返すと、くり返すほど笑いになる。
- **刻**: 同じ考えが戻ってくるのは、失敗ではありません。むしろ、**新しい見方を思い出す練習のチャンス**です。
- **旅路**: 番組に「**あのボケ、また来た**」のボタン。押すと、その妖怪に前回の自分が入れた**オチが、10秒で出てくる**。「天丼 3回目」と数える。くり返すボケは、恥ではなく持ちネタになる。

### 4. オチ札 ― 新しいセリフを持ち歩く
- **言野**: 言い直したセリフを、**お守りの札**のように持ち歩けるといい。番組に「今日のオチ札」として、過去の自分のオチが一枚ずつ出てくる。
- **刻**: 間をあけて思い出すほど、記憶は定着します（間隔をあけた想起）。数日おきに、前のオチが顔を出す仕組みは理にかなっています。

### 5. 再演は、続編として
- **幕田**: もう一度上演するとき、毎回ボケから始める必要はありません。「**前回のオチから始まる続編**」。妖怪が出てきて「また来たぞ」とボケると、あなたが前回のオチで即ツッコむ。数秒で終わる、天丼の一席です。

### 6. ネタ帳の主役を入れかえる
- **旅路**: ネタ帳の一覧は、**オチが大きく、ボケは小さく**。読み返したときに目に入るのが、新しいセリフになるように。

## 第2幕 論争 ― 気持ちを受けとめる一文は、全部いらないのか

- **言野**: 迷うのは、本当にしんどい人への声かけです。
- **刻**: 区別しましょう。**始まる前**、つらさを書いている最中は、受けとめる一文が支えになります。でも、**認知が変わったあと**に感覚へ戻す一文は、いらない。
- **旅路**: そして、命に関わることばが書かれたときの安全の案内（相談先・休憩所）は、どんな場合も残す。
- **結論**:
  - 終わりの場面では、元の感覚に引き戻すことばを使わない
  - 始まる前・書いている最中の受けとめは、必要なところだけ残す
  - 安全の案内は、そのまま残す

## 第3幕 提案（優先順）

| 優先 | 提案 | 中身 | ねらい |
|---|---|---|---|
| 1 | **測り方の転換** | 終演後は「新しいセリフ、どれくらいしっくり？」と「いまの気分の名前（ほっと・すっきり・ふつう・まだもやもや）」。古いセリフの信じ度と、元の気分の強さは聞かない | 測るたびに、新しい見方が強くなる |
| 2 | **幕切れの演出** | 終演画面の主役を「あなたのオチ」に。大きく、もう一度。数字は小さく | 記憶に残る終わりを、オチにする |
| 3 | **天丼ボタン** | 番組に「あのボケ、また来た」。妖怪を選ぶと前回の自分のオチが出て、天丼の回数を数える | くり返す考えを、持ちネタに |
| 4 | **オチ札** | 番組に、過去のオチが数日おきに一枚ずつ出る | 間隔をあけた想起で定着 |
| 5 | **続編の再演** | 再演は前回のオチから始まる短い一席 | 古いボケを長く再生しない |
| 6 | **ことばの総点検** | 終わりの場面の「重さ」「ざわざわ度」「しんどい」などを、前を向くことばに（ながめ席は「いま、どんな感じ？」、笑い噺は「いまなら、どう話せる？」） | 引き戻しをなくす |
| 7 | **ネタ帳の主役交代** | 一覧はオチを大きく、ボケは小さく | 読み返しで、新しいセリフに触れる |
