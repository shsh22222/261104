## 第1幕 発散 ― 「思考はフィクション」を笑いで届ける

ユーザーからの声「すべての思考は幻想だということに、コメディ的にアプローチできる」を出発点に、各分野から案を出しました。

### 落語の「見立て」

- **こはぎ（落語家）**: 落語家は、扇子一本でそばをすすって見せます。手ぬぐい一枚で、財布にも手紙にもなる。お客さんには、ないはずのそばが見えるんです。
- **神崎（神経科学）**: 脳も同じことをしています。脳は、目や耳から入る情報を待つより先に「たぶんこうだろう」と予測して、世界の像をつくっている、という考え方があります（予測処理）。考えも、脳の予測が流す「イメージ映像」のようなものです。
- **静寂**: 妖怪は扇子一本で、ありもしない大惨事を見せる名人、というわけですね。
- → 採用: 高座の画面に「見立て」の説明を入れる。

### テレビのテロップ

- **筆坂（放送作家）**: テレビには、こわいくらい便利な一行があるんです。「※イメージです」「※個人の感想です」「※この物語はフィクションです」。
- **浪速**: 妖怪のボケに「※イメージです」って出たら、それだけで笑いますわ。
- **春風（ユーモア研究者）**: 笑いの理論に「良性の違反」という考え方があります。何かが「おかしい、危ない」と感じると同時に、「でも安全だ」とわかったときに、人は笑う。こわい考えに「※フィクションです」と出た瞬間、こわい考えが「安全なおかしさ」に変わるんです。
- → 採用: **高座でセリフにテロップを貼れる**ボタン。**上演の最後に「※この漫才はフィクションです」のテロップ**。

### 持ちネタ集（見本の大量化）

- **筆坂**: ネタは量が質を生みます。見本がたくさんあれば、「あ、これ私だ」と思える一本に必ず出会える。
- **深町（スキーマ療法家）**: たくさん作るなら、分類の軸を理論で決めましょう。考えの奥には、昔から続く「中核信念」があります。ジュディス・ベックは中核信念を、**無力**（自分には何もできない）、**愛されない**（受け入れてもらえない）、**価値がない**（自分はダメだ）の3つに大きく分けています。
- **森田**: 縦軸に認知の歪み12種（妖怪12体）、横軸に生活の場面、タグに中核信念。これなら漏れなく並べられます。
- **筆坂**: 場面は8つにしましょう。仕事・学校、友人・職場の人間関係、恋愛・パートナー、家族、SNS・ネット、体・健康・見た目、お金・将来、家のこと・生活。12 × 8 で **96本**。
- **こはぎ**: 寄席には「ネタ帳」があって、その日に誰が何のネタをやったかを書いておくんです。96本の一覧は、寄席の「ネタ表」にしましょう。
- → 採用: **持ちネタ集 96本**。ネタ表（12×8のマス目）と、場面・妖怪・奥にある思いで絞り込める一覧。

## 第2幕 衝突 ― 5つの論争

### 論争1 「考えはすべて幻想」と言い切っていいか

- **黒川（精神科医）**: 気をつけたいのは、借金、いじめ、病気、喪失など、現実の困りごとまで「幻想」と言ってしまうことです。それは、つらさを否定する「無効化」になります。
- **深町**: 「あなたのつらさは気のせい」と受け取られたら、逆効果ですね。
- **静寂**: 区別すべきは、出来事と、出来事についての頭の中のセリフです。出来事は本物。でも、頭の中のセリフには、いつも脚色が入っている。
- **こはぎ**: 落語でも、そばはないけど、お客さんのお腹は本当に空きます（笑）。
- **筆坂**: テロップを二行にしましょう。「※この漫才はフィクションです。登場する考えは、実在の事実・未来とは関係ありません。」「ただし、あなたのしんどさは本物です。」
- **灯**: 二行目があると、救われます。笑ったあとに、ちゃんと受け止めてもらえる。
- **結論**: **出来事とつらさは本物、頭の中のセリフはフィクション（脚色つき）**。これを全体の言葉づかいの基準にする。

### 論争2 見本を見せると、正解を写すだけにならないか

- **森田**: 見本の言い直しをそのまま写しても、自分の考えは変わりません。CBTで大事なのは、自分で検討する過程です。
- **筆坂**: でも、白紙からツッコミを考えるのは難しい。見本は「型」を覚える教材です。
- **柏木**: 使い方を二つに分けましょう。「観る」（見本の上演を観て、型を覚える）と、「自分のネタにする」（ボケだけを借りて、ツッコミと言い直しは自分で書く）。
- **結論**: 「このネタで自分の漫才を作る」を押すと、**ボケだけが入った状態**で始まる。ツッコミの答えと言い直しは、自分の言葉で書く。

### 論争3 中核信念のラベルは重すぎないか

- **灯**: 「価値がない」という文字を見るだけで、刺さる日があります。
- **深町**: 名前をつける意味は、「これは自分の本質ではなく、昔からの思いこみのクセだ」と距離をとるためです。
- **静寂**: 言い方を変えましょう。「価値がない」ではなく「ダメな気がする」。「気がする」をつければ、事実ではなく思いだと伝わります。
- **結論**: 表示は「**できない気がする**（無力）」「**好かれない気がする**（愛されない）」「**ダメな気がする**（価値がない）」。選ぶのは任意で、「わからない」も選べる。

### 論争4 ツッコミのくり返しは、笑いか飽きか

- **浪速**: 同じボケのくり返しは「天丼」という笑いの技法です。でも、ツッコミの言い回しが毎回同じだと、機械的に聞こえます。
- **春風**: 笑いには「予想とのズレ」が必要です。同じ言い回しは、ズレが生まれません。
- **森田**: ただし、質問の中身は変えないでください。「証拠は？」を聞くことが技法の核です。
- **結論**: ツッコミの**中身（質問）は固定、言い回しだけ3パターン**からランダムに変える。

### 論争5 ふりかえりは「成績表」にならないか

- **倉橋（行動経済学）**: 前の週と比べたり、点数をつけたりすると、それは成績表です。下がった週に落ちこみます。
- **灯**: 「今週は少なかった」と見せられるのは、つらいです。
- **柏木**: 比べない、評価しない、ただ並べる。名前も「番付」ではなく「楽屋日誌」に。
- **結論**: この7日間に**やったことを並べるだけ**。前週との比較、目標、達成率は出さない。

## 第5幕 持ちネタ集の分類

### 三つの軸

| 軸 | 中身 | 出どころ |
|---|---|---|
| 縦軸：認知の歪み（12） | 全か無か、過度の一般化、心のフィルター、マイナス化、心の読みすぎ、先読みの誤り、破局視、感情的決めつけ、すべき思考、レッテル貼り、個人化、他人との比較 | Burnsの認知の歪みリスト（＋比較） |
| 横軸：生活の場面（8） | 仕事・学校／友人・職場の人間関係／恋愛・パートナー／家族／SNS・ネット／体・健康・見た目／お金・将来／家のこと・生活 | 相談で多い場面から選定 |
| タグ：奥にある思い（3） | できない気がする（無力）／好かれない気がする（愛されない）／ダメな気がする（価値がない） | ジュディス・ベックの中核信念の3分類 |

### 一本のネタの形

```
ボケ        「既読なのに返事が来ない。嫌われたんだ」      … サトリ（心の読みすぎ）／友人／好かれない気がする
ツッコミ1   エスパーか！ → 忙しい、あとで返そうと思った、寝落ちした、の可能性も
ツッコミ2   証拠あるんかい！ → 昨日まで普通にやりとりしていた
言い直し    返事がない理由はわからない。嫌われたと決めるのはまだ早い。
テロップ    ※この漫才はフィクションです。ただし、あなたのしんどさは本物です。
```

### 書き方の基準（放送作家と臨床家の合意）

- ボケは、実際に頭に浮かびがちな言い回しで、一行に収める。
- ツッコミの答えは、**事実**か**別の見方**か**小さな行動**のどれかにする。根性論や「ポジティブに」は書かない。
- 言い直しは、ボケを否定しきらず、**現実に合ったバランス**にする（「〜かもしれない。でも〜」）。
- 体・健康のネタは、「続くなら受診する」などの現実的な行動を残し、確認行為や我慢を勧めない。
- 誰かを笑いものにしない。笑うのは、いつも考え（妖怪）。
