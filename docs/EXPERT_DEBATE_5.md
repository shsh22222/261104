## 第1幕 福さがしは「朝に探す」か「夜に思い出す」か

- **桐生（UI）**: 朝にお題を見て一日探す形は、朝にアプリを開くことが前提です。開かなかった日は、何も起きない。夜、寝る前に一日を締めくくる「儀式」のほうが、習慣の置き場所としては強いです。
- **筆村（筆記療法）**: 精神科医の樺沢紫苑さんが勧めている「3行ポジティブ日記」は、寝る前に、その日のよかったことを3つ書くものです。ポジティブ心理学の「三つのよいこと」とも近い。書くことで、一日の記憶が「よかったこともあった日」として整理し直されます。
- **秋津（学習科学）**: 「何かよかったことは？」と白紙で聞かれると、人は思い出せません。記憶は**手がかり**があると出てきます。「おいしい一口は？」「ありがとうと言えることは？」とテーマを渡す。さらに、朝・昼・夕方・夜と一日を**巻き戻す**と、場面ごとに記憶がよみがえります。
- **灯（傍聴）**: 「無理やりでも、こじつけでもいい」と言ってもらえると、かえって楽です。立派なことを書かなきゃ、が消えるので。
- **公平（倫理）**: こじつけを「遊び」として歓迎するのは賛成です。ただ、「今日は見つからなかった」は必ず残してください。
- **空山（禅僧）**: 朝のお題も、捨てなくていい。朝に「今日は『やさしい音』」と聞いておけば、夜に思い出す手がかりになります。種まきと収穫です。

**結論**
- 主役は**夜の福日記**。3行、それぞれに「レンズ」（思い出すテーマ）がつく。1行目は今日のお題（もの・感覚）、2行目は人とのこと、3行目は自分のこと。レンズはタップで変えられる。
- 「**一日の巻き戻し**」（朝・昼・夕方・夜の思い出しの質問）で、記憶を探す手がかりを渡す。
- **こじつけ大歓迎**。「今日は見つからなかった」も選べる。
- 朝のお題は「レンズの予告」として残す。昼に見つけたものは、夜の日記にワンタップで入れられる。
- 夜に書き終えたら、そのまま**おやすみ席**へつなげる。

## 第2幕 ながめ席に「息といのち」の棚を

- **根岸（ソマティック）**: エックハルト・トールが勧める「インナーボディ」は、体を外から見るのではなく、内側から感じる練習です。手の内側の「生きている感じ」、ジンジン、ぽかぽかから始めると、多くの人が感じやすい。そこから腕、足、胴体へ広げ、最後は体全体を一つのいのちとして感じます。
- **根岸**: 大事なのは、「何も感じない」も正解にすることです。感じようと力むと、かえって頭が忙しくなります。
- **空山（禅僧）**: 「いま」「ここ」と息に合わせて唱えるのは、息を数える坐禅の工夫に近いものです。それたら戻る。戻ることこそが修行で、それたことは失敗ではありません。
- **息吹（呼吸）**: ネドじゅんさんが紹介している今ここ呼吸やエレベーター呼吸は、意識を頭から下へ下ろしていく呼吸です。アプリにするなら、吐く息を長めに、深く吸おうとしすぎないこと。息苦しくなったら、すぐふつうの呼吸に戻すこと。
- **嵐山（ゲーム）**: エレベーター呼吸は、エレベーターの階数表示がそのまま楽しい。吐くたびに「ポーン、4階、のどです」と一階ずつ下りて、最後は「ハラ階」。
- **黒川（傍聴）**: 名前は「参考にした」と明記して、細部はココロ寄席なりのアレンジだと書いておきましょう。原典の正確な方法は、それぞれの本で確かめてもらう。

**結論**: ながめ席に4つ目の棚「**息といのち**」を新設し、3演目を加える。

| 演目 | 中身 | 参考 |
|---|---|---|
| インナーボディ | 手 → 腕 → 足 → 胴体 → 全身の「生きている感じ」。最後は内側に根をおろしたまま、目を開けて外を眺める | エックハルト・トールのインナーボディ |
| 今ここ呼吸 | 吸うとき「いま」、吐くとき「ここ」。10呼吸。それたら「もどった」をタップ（戻った回数を数える） | ネドじゅんの今ここ呼吸 |
| エレベーター呼吸 | 吐く息ごとに意識のエレベーターが一階ずつ下りる。頭 → のど → 胸 → みぞおち → おなか → ハラ。ハラ階で3呼吸とどまる | ネドじゅんのエレベーター呼吸 |

おまかせの組み合わせも見直し、寝る前の「おやすみ席」は「ぎゅっとふわっ → エレベーター呼吸」にする。

## 第3幕 図鑑に「伝説の妖怪」と「金色の姿」を

- **星野（収集）**: 収集が楽しくなるには、レア度の層と、出会いのドラマが必要です。いまは通常の妖怪だけ。そこに**伝説**の層を足しましょう。
- **天野（神話学者）**: 日本の伝承には、ふさわしい霊獣がそろっています。すべての妖怪を知るという**白澤**、道を導く三本足の**八咫烏**、悪い夢を食べる**獏**、疫病よけの**アマビエ**、山の修験者の**大天狗**、雷とともに走る**雷獣**、そしてよい世に現れる**麒麟**。
- **公平（倫理）**: 出現の条件が大事です。ランダム、課金、回数稼ぎで出すと、ガチャと同じ仕組みになります。条件は「**上手にできたこと（熟達）**」に結びつけ、図鑑に**条件をそのまま書いて公開**してください。隠された条件は、人を必要以上に引きとめます。
- **星野**: もう一つ、「**進化**」です。なかよし度が最大の5になった妖怪は、金色の姿になる。ずっと付き合ってきた妖怪が、いちばん輝く。
- **桐生（UI）**: 出現の演出は、暗転、稲光、そして登場。ここだけは派手でいい。

**決定：7体の伝説と出現条件（すべて図鑑で公開）**

| 伝説 | 称号 | 出現条件（熟達） |
|---|---|---|
| 大天狗 | ツッコミの達人 | 1回の漫才で3つのツッコミに答え、信じ度を30ポイント以上下げる |
| 八咫烏 | 注意の導き手 | お囃子の聞き分けを最後まで3回 |
| 獏 | 夢を食べる者 | おやすみ席を最後まで3回 |
| アマビエ | 福を見つける名人 | 福日記を書いた日が7日（続けてでなくていい） |
| 雷獣 | 早押しの雷 | 大喜利「妖怪当て」で10問すべて正解 |
| 白澤 | すべてを知る聖獣 | 考え方のクセの妖怪12体すべてに出会う |
| 麒麟 | 寄席の守り神 | ほかの伝説6体すべてに出会う |

## 第4幕 ゲームのモード「大喜利」

- **嵐山（ゲーム）**: ながめ席はゲーム性がありつつ、静かであることが価値です。ゲーム性を強めるなら、別の場所に分けたほうがいい。寄席には、出演者がお題に答えて笑いをとる「大喜利」のコーナーがあります。そこをゲームモードにしましょう。
- **嵐山**: 2本立てにします。頭を使う**早押しクイズ**と、指を使う**アクション**です。
- **秋津（学習科学）**: クイズは「思い出す練習」になるので、妖怪（認知の歪み）の見分け方を覚えるのに向いています。持ちネタ集の96本を問題に使いましょう。間違えたときは、その場で見分け方を見せる。すぐのフィードバックが学習には効きます。
- **根岸・空山**: アクションは「いま」を拾い、「考え」は見送るゲームにしたい。考えをつかんでしまっても**減点しない**。「気づいて離せばOK」と伝える。
- **公平（倫理）**: 点数は**自己ベストだけ**。ランキング、プレイ回数の制限、連続ボーナスはつくらない。
- **桐生（UI）**: タブも見直しましょう。おみくじは番組の中に置き、タブには大喜利を。

**決定**

| ゲーム | 中身 | ねらい |
|---|---|---|
| 妖怪当て早押し | 持ちネタ集のボケを見て、どの妖怪のしわざかを4択で当てる。ときどき「効くツッコミはどれ？」の問題も。10問。速さとコンボでボーナス。間違えたら見分け方を表示し、終わりに「見分けにくかった妖怪」を出す | 認知の歪みを見分ける練習（想起練習） |
| いまひろい | 下から浮かんでくる泡のうち、「いま」の感覚（足の裏・息・風の音…）だけをタップで拾い、「考え」（明日の会議・あの一言…）は見送る。45秒 | 注意を「いま」に向け直す練習、考えとの距離のとり方 |

## 第5幕 UIの手ざわり

- **桐生**: ホームは、時間帯で入口を変えましょう。**朝**は今日のお題、**夜**は「福日記 → おやすみ席」。開いた瞬間に、いまやることが一つ見える。
- **桐生**: 画面の切りかえには、ごく短いフェードを。図鑑はカードの枠でレア度がわかるようにします（通常・金色・伝説）。
- **嵐山**: ゲームの正解には、ハリセンの音とコンボの数字。気持ちよさは手を抜かない。
