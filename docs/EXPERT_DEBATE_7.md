# ココロ寄席 第七回設計会議 ― 世界は、相方

> 第七回の議題は、ユーザーからの三つの声です。
> 1. 「妖怪漫才で認識が変わっていく流れは素晴らしい。ただ、**それぞれのセリフの位置づけ**が体感でわかるともっといい。頭の声がどう変わっていくのか、ステップの説明がほしい」
> 2. 「頭のセリフをいろんな声で再生するのはACTに沿っていて素晴らしい。**声を変える以外**にも、文字を揺らす、コメディ的に再生するなどのひねりを」
> 3. 「思考の歪みは妖怪漫才で扱える。あとは、ユーザーを**肯定的な世界観**にどう導くか。コメディを、私たちの認識や出来事、世界の感じ方とどう結びつけるか」
>
> 今回は、笑いの「作り手」と「研究者」を中心に、天才肌の10名を集めました。登場人物は、役割を明確にするための**架空の人物**です。

## 第0幕 台本を読む ― 漫才作家の指摘

喜多は、ユーザーが作った漫才の台本を20本読んでから、口を開きました。

- **喜多（漫才作家）**: 流れはいい。気分、ボケ、鑑定、高座、ツッコミ、言い直し。これは漫才の構造そのものです。ただ、**書く人に「このセリフは何の役か」が見えていない**。だから、ボケをきれいに書きすぎたり、ツッコミの答えに「気にしない！」と書いたりする。
- **喜多**: 漫才の台本では、セリフの一つひとつに役目があります。**フリ**は状況を見せる。**ボケ**はずらす。**ツッコミ**はずれを指さす。**オチ**は着地させる。役目がわかると、書く手が迷わない。
- **戸川（認知療法）**: 思考記録表も同じです。「状況」「自動思考」「感情」「根拠と反証」「適応的思考」。欄の役目を知らずに埋めると、「状況」の欄に考えを書いてしまったり、「適応的思考」が「がんばる！」になったりする。臨床でいちばん多いつまずきです。
- **灯（傍聴）**: 私も、言い直しのところで「なんて書けばいいんだろう」と止まりました。例はあるけど、なぜそれがいいのかがわからなかった。

## 第1幕 セリフの位置づけ ― 「台本の地図」

### 1. 台本の書式を借りる

- **能登（脚本家）**: 舞台の台本には、三つのものしかありません。**役名**、**セリフ**、**ト書き**。ココロ寄席の6つのステップは、この書式にそのまま乗ります。

| ステップ | 台本での役目 | 頭の声はこう変わる | 出した人 |
|---|---|---|---|
| 一 気分 | **開演前の天気予報** | 「なんだかザワザワ」→「不安が70くらい」 | 戸川 |
| 二 ボケ | **ネタの素材**（頭の声をそのまま書き起こす） | 頭の中で鳴っている →「文字になって、外に出た」 | 喜多 |
| 三 鑑定 | **役名**（だれのセリフか） | 「本当のことだ」→「サトリのクセだ」 | 能登 |
| 四 高座 | **ト書き**（セリフと自分のあいだに距離） | 「〜と思われる」→「……という考えが浮かんでいる」 | 水無瀬 |
| 五 ツッコミ | **相方**（問い＋事実の答え） | 「それしかない」→「ほかの見方もある」 | 喜多・戸川 |
| 六 言い直し | **オチ**（自分で選んだ言い方） | 「ほかの見方もある」→「こう言うことにする」 | 喜多 |

- **能登**: ト書きがいちばん大事です。「（サトリ、得意げに）」と書いた瞬間、そのセリフは**登場人物のセリフ**になる。書いた人は、作者の席に座る。
- **水無瀬（ACT）**: それは脱フュージョンの核心です。「私は変な人だと思われる」と「『変な人だと思われる』という考えが浮かんでいる」の差。ト書きは、その差を形にします。

### 2. 「頭の声との距離」を目に見せる

- **宇佐美（タイポグラフィ）**: 6つのステップで、**頭の声との距離**がどう変わるかを一本の線で見せましょう。左端は「くっついている」、右端は「えらべる」。ステップが進むたびに、点が右に動く。
- **戸川**: 点が右へ動くのは「考えが消える」ことではありません。**距離が変わる**だけ。そこは言葉で添えたい。

### 3. 台本は、書きながら育つ

- **喜多**: 説明ページだけでは足りない。書いている最中に、**いまの台本**が見えているといい。ボケを書けば「？？？「……」」と役名が空いた台本が出る。鑑定すれば役名が入る。ツッコミを書けば相方のセリフが増える。最後の行だけが空いている――そこが「オチを書くところ」だと、体でわかる。
- **能登**: 台本用紙らしく、役名は朱、ト書きは小さく丸かっこで。空いている行には「← いまここ」。

### 4. オチの型 ―「たしかに・でも・だから」

- **喜多**: いいオチには型があります。いったん**受けて**、**ずらして**、**着地**する。言い直しも同じ。
  - **たしかに**（気持ちを受けとめる）
  - **でも**（事実・別の見方。ツッコミの答えを借りてくる）
  - **だから**（次の一歩、または自分で選ぶ言い方）
- **戸川**: 適応的思考の条件は「本人が信じられること」です。ポジティブすぎると心が信じない。否定しきると反発が来る。この三段は、そのバランスを取りやすい。
- **笹木（ユーモア心理学）**: 書いた言い直しに、**妖怪の口ぐせが残っていないか**を見てあげるのはどうでしょう。「全部」「絶対」「みんな」が残っていたら、そっと知らせる。逆に「絶対うまくいく！」は、ポジティブの押しつけとして知らせる。大喜利の「言い直し問題」で練習したことが、ここで生きます。
- **喜多**: 長すぎるオチは、ウケない。ひとことに絞ると届く。

## 第2幕 声以外の脱フュージョン ―「文字で遊ぶ」「番組にする」

- **水無瀬（ACT）**: ACTの脱フュージョンには、声を変える以外にもたくさんの技法があります。歌う、ゆっくり言う、**同じ言葉をくり返して意味をほどく**（ティチェナーの反復）、「〜という考えが浮かんでいる」と言い換える、**葉っぱに乗せて流す**。共通点は、**考えの「意味」ではなく「形」を見る**こと。
- **宇佐美（タイポグラフィ）**: 文字は、意味を運ぶ乗り物です。乗り物を揺らすと、乗っている意味の迫力が変わる。私の案はこれです。

### 文字で遊ぶ

| 遊び | 動き | 気づき |
|---|---|---|
| **ぷるぷる** | 一文字ずつ小刻みに震える | 震えているのは文字。あなたではない |
| **ふにゃふにゃ** | 文字が波打つ | ふにゃふにゃのセリフに、さっきの迫力はある？ |
| **さかさま** | 文字の並びが逆になる（読み上げも逆） | 並べ方しだいで、ただの音 |
| **ばらばら** | 文字が床に落ちて散らばる | ばらばらにすると、ただの文字。意味は頭がつけている |
| **連呼** | 一番強い言葉を20回くり返す | くり返すと、意味がほどけて音になる |
| **ピコピコ** | 昔のゲームの村人のように、一文字ずつ電子音つきで出る | 村人のセリフなら、聞き流せる |

- **遠野（映画監督）**: 私は「番組にする」を提案します。人は、同じ内容でも**どの番組の形式で流れてくるか**で受け取り方が変わる。

### 番組にする

| 番組 | 形式 | 気づき |
|---|---|---|
| **実況中継** | 「おーっと！ ここでサトリ選手、〜を放ったー！」 | 実況すると、あなたは選手から観客席へ |
| **天気予報** | 「頭の中は、ところにより〜。午後には晴れ間も」 | 考えは天気。来て、いつか去る |
| **ニュース速報** | 「【速報】サトリが〜と発言。本人は『いつものこと』」 | 速報は大げさ。すぐ次のニュースに変わる |
| **映画の予告編** | 「この秋、あなたの頭の中で上映――」 | 予告編は、本編よりずっと怖く作ってある |
| **テロップ** | 「※イメージです」（第一回から） | 考えはフィクション |

- **水無瀬**: 一つだけ、はっきりさせておきたい落とし穴があります。脱フュージョンは、**考えを追い出すための技ではありません**。「消えろ」と思って遊ぶと、それは考えとの戦い（コントロール）になって、かえって強まる。ねらいは、**考えを考えとして見る**こと。考えが残っていても、いい。
- **灯（傍聴）**: 「ふざけて追い払う」じゃなくて、「いっしょに遊ぶ」なんですね。それなら、しんどい日でもできそうです。
- **喜多**: 高座で選んだ遊び方は、上演のボケのところでも再現しましょう。自分で選んだ「ぷるぷる」で妖怪が登場したら、それだけで笑える。

## 第3幕 肯定的な世界観へ ― 3つの論争

### 論争1 肯定的な世界観とは「なんでも前向きに」ではないのか

- **白鷺（哲学者）**: 「前向きに考えよう」は、多くの人にとって命令に聞こえます。命令された前向きさは、心が信じない。私が提案したいのは、**世界を敵ではなく、相方として見る**という世界観です。
- **早乙女（インプロ）**: 即興劇では、相手が何を言っても「イエス・アンド」で受けます。相手のセリフを否定しない。でも、言いなりにもならない。**受けて、足す**。人生の出来事も、世界からの**ネタ振り**だと思うと、少し軽くなる。
- **喜多**: 相方は、ときどきひどいボケをかます。それにツッコむのも愛情です。世界がボケたら、ツッコめばいい。全部を「いいこと」にしなくていい。
- **白鷺**: ベルクソンは『笑い』で、人が笑うのは**生きたものに機械的なこわばりが貼りついたとき**だと書きました。認知の歪みは、まさに考えのこわばりです。笑いは、そのこわばりをほぐすためにある。
- **結論**: 目指す世界観は「**世界は、相方。**」。出来事を全部よいことにするのではなく、出来事を**ネタ振り**として受け、自分のひとことを返す。ポジティブの押しつけはしない。

### 論争2 つらい出来事を笑いにしていいのか

- **遠野（映画監督）**: チャップリンの言葉があります。「人生は、クローズアップで見れば悲劇、ロングショットで見れば喜劇だ」。笑いには**距離**が要る。
- **笹木（ユーモア心理学）**: 研究でも同じです。笑いは、**害のない「ずれ」**として感じられたときに起きる（良性違反理論）。近すぎる出来事は、まだ「害」のまま。時間や心理的な距離ができると、同じ出来事が笑える。
- **笹木**: もう一つ大事な研究があります。ユーモアには4つのスタイルがあり、**自分を下げる笑い**（自虐で人に合わせる）は、落ちこみと結びつきやすい。一方で、**自分を励ます笑い**（困ったことの中におかしみを見つける）は、心の健康と結びつく。
- **月見亭（落語家）**: 落語の世界には「**業の肯定**」という言葉があります。落語は、人間の弱さ、だらしなさ、怖がり、見栄っぱりを、責めずに笑う芸だと。与太郎も八っつぁんも、ダメなところだらけ。でも、客はその人を愛してしまう。**自分を下げるのではなく、人間らしさを愛でる**。それが落語の笑いです。
- **灯（傍聴）**: 自虐ネタを言うと、そのあと落ちこむことがありました。違いがわかってほっとしました。
- **結論**:
  - 新しい演目は「**ちいさなしくじり**」から。重さが大きい出来事は「まだ笑いにしなくていい」と伝え、妖怪漫才・ながめ席・休憩所を案内する。
  - 「ダメ人間」「バカ」などの自分を下げる言葉が入ったら、「人間らしさを愛でる笑いへ」とそっと知らせる。
  - つらさの言葉が入ったら、相談先を案内する。

### 論争3 どうやって「笑える距離」をつくるか

ここで、6つの「**芸人の目**（レンズ）」が出そろいました。

| レンズ | 問い | 出どころ | 出した人 |
|---|---|---|---|
| **引きの画** | カメラをうんと引いて、空から眺めると？ | チャップリン「ロングショットで見れば喜劇」、自己距離化の研究 | 遠野 |
| **10年後の笑い話** | 10年後の自分が、酒の席で話すなら？ | 「悲劇＋時間＝喜劇」、時間的距離 | 喜多 |
| **人間だもの** | この場面の、人間らしいところは？ | 落語の「業の肯定」、セルフ・コンパッション（共通の人間性） | 月見亭 |
| **塞翁が馬** | このおかげで、起きるかもしれないことは？「かもね」で | 故事「人間万事塞翁が馬」、意味づけの保留 | 白鷺 |
| **実況中継** | 実況アナと解説者が、その場面を中継すると？ | 観察者の視点、脱フュージョン | 早乙女 |
| **あるある** | 同じことをした人、世界に何人いそう？ | 共通の人間性（セルフ・コンパッション） | 笹木 |

- **月見亭**: そして最後は、**高座で一席**。まくら、フリ、しくじり、芸人の目、オチ、「お後がよろしいようで」。自分のしくじりを、自分が噺家になって語る。語り手の席に座った瞬間、あなたはもう、しくじった本人ではなく**語る人**です。
- **戸川**: 前後で「その出来事の重さ」を測りましょう。出来事は変わらなくても、**持ち方**が変わったことが数字でわかる。

### 世界のボケ拾い ― 毎日の「おかしみ」

- **笹木**: 研究で効果が報告されている練習に「**三つのおもしろかったこと**」があります。毎晩、その日おもしろかったことを3つ書く。1週間続けた人で、幸福感が上がり、落ちこみが下がったという報告がある。福さがし（三つのよいこと）の、笑い版です。
- **早乙女**: 世界は、けっこうボケています。看板の誤字、猫の寝相、自分の言いまちがい。拾ったら、ひとことツッコむ。それで十分。
- **白鷺**: 「よいこと」を探すのが苦しい日でも、「おかしなこと」なら見つかることがある。**肯定は、おかしみからでも始められる**。

## 閉会のことば

- **喜多**: フリがあって、ボケがあって、ツッコミがあって、オチがある。台本の地図があれば、だれでも漫才作家になれます。
- **水無瀬**: 考えは、追い出さなくていい。ぷるぷる震えていても、舞台の上にいるなら大丈夫。
- **月見亭**: しくじりは、噺の種。お後がよろしいようで。
- **白鷺**: 世界は、ときどきひどいボケをかましてくる相方です。ツッコんで、笑って、また舞台に立つ。
- **灯（傍聴）**: 「笑わなくていい日もある」と書いてあるのが、いちばんうれしかったです。
