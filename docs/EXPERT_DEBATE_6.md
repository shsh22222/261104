## 第0幕 プレイテスト ― 伝説のゲームデザイナーが遊んでみた

会議の最初の1時間、宮城は黙って大喜利を遊び続けました。その後のひとことです。

- **宮城（伝説のゲームデザイナー）**: 気持ちいい。ハリセンの音もいい。ただ、3回目で飽きました。理由ははっきりしています。
  1. **妖怪当ては、消去法で当たる。** 4つの選択肢が「似ていない妖怪」どうしなので、ボケの言葉の端っこで答えがわかってしまう。
  2. **いまひろいは、色で当たる。** 「いま」は金色、「考え」は紫。文字を読まなくても、色だけで正解できる。**判断がない**んです。
  3. **毎回、同じ形。** 10問やって終わり。45秒やって終わり。途中で何かを**選ぶ**場面がない。
  4. **うまくなった実感がない。** 点数は上がるけれど、何がうまくなったのかが見えない。
- **宮城**: 簡単なこと自体は悪くありません。最初の5秒で楽しいのは大事です。でも、**判断のない簡単さは飽きる**。遊びの核は「判断」と「手触り」です。

## 第1幕 発散

### 1. 判断を取りもどす

- **千石（パズル）**: 妖怪当ての選択肢に、**まぎらわしい妖怪どうし**を並べましょう。「心の読みすぎ（サトリ）」と「先読みの誤り（くだん）」、「全か無か（ぬりかべ）」と「過度の一般化（イツモ入道）」。ここを見分けられるかが、本当の腕です。
- **宮城**: いまひろいは、段階が上がったら**色をなくす**。泡はすべて同じ色で、文字を読んで判断する。タップした瞬間に色が出て、正解がわかる。
- **森田（傍聴）**: CBTとしても大事な区別があります。**事実と考え（解釈）の区別**。そして、**現実に合った言い直しと、ポジティブの押しつけの区別**。この二つは、ゲームにしたら良い練習になります。
- **千石**: では問題の種類を増やしましょう。「言い直しはどれ？」――バランスのいい言い直し、ポジティブの押しつけ、まだボケのまま、の三つから選ぶ。

### 2. いまひろいに新しい泡

| 泡 | ふるまい | 込めた意味 | 出した人 |
|---|---|---|---|
| **福の泡** | 長押しで「味わう」とボーナス | よいことは、少し長くとどめると残る（味わい） | 鳴海・秋津 |
| **体のざわざわ** | 「胸のざわざわ」「肩のこわばり」も、拾うべき「いま」 | 不安の体の感覚も、いまの感覚。考えではない | 森田 |
| **増える考え** | 考えの泡をつかむと、二つに割れて増える | 考えに手を出すと、考えは増える（反すう） | 宮城 |
| **いま三昧（フィーバー）** | 10連続で「いま」を拾うと、6秒間ポイント2倍 | 注意が「いま」にそろったときの気持ちよさ | 鳴海 |

- **宮城**: 「つかむと増える」は、説明しなくても体でわかる。ゲームが教えてくれるのが一番いい。

### 3. 毎回ちがう ―「百鬼夜行」

- **霧島（ローグライト）**: 一回の遊びを「一夜」にしましょう。四つの演目（妖怪当て・言い直し・事実か考えか・いまひろい）を毎回ちがう順番でこなし、最後に大トリとして**百鬼夜行**が来る。
- **霧島**: 演目と演目のあいだで、三枚の**芸の札**から一枚を選ぶ。「長考の札（制限時間が延びる）」「替え提灯（命がひとつ増える）」「お目付け役（選択肢がひとつ減る）」……。選んだ札で、その夜の戦い方が変わる。
- **黒須（アーケード）**: 命は提灯三つ。まちがえると一つ消える。全部消えたら、その夜はおしまい。
- **公平（倫理）**: 大トリの百鬼夜行で、妖怪を「倒す」のはやめてください。この寄席の原則は「退治しない」です。
- **宮城**: 見破られた妖怪は、**お辞儀をして行列を離れる**。それで十分に気持ちいい。
- **星野（収集）**: 提灯を一つも失わずに百鬼夜行を越えたら、隠れていた伝説「**鵺（ぬえ）**」が現れる、というのはどうでしょう。正体のつかめない妖怪です。

### 4. うまくなった実感 ―「見分けの星」と「苦手克服」

- **秋津（学習科学）**: 妖怪ごとに、正しく見分けた回数と正答率を記録して、**見分けの星**（★〜★★★）にしましょう。図鑑にも出す。
- **秋津**: さらに、まちがえやすい妖怪を多めに出す「**苦手克服**」を。苦手を集中して練習するのが、いちばん伸びます。
- **早瀬（フロー理論）**: 難しすぎると不安になり、簡単すぎると退屈になる。そのあいだの「フロー」に置くには、**段位を選べる**ことと、腕に合わせて上がることの両方が要ります。
- **黒須**: 妖怪当てに段位を。**前座**（4択・12秒）、**真打**（6択・9秒・まぎらわしい選択肢・言い直し問題）、**名人**（6択・7秒・すべての問題）。上の段位は、下で一定の点を取ると開く。

### 5. 毎日のちょっとした新しさ ―「今夜の百鬼夜行」

- **嵐山**: その日だけの百鬼夜行を。日付で問題と順番が決まり、その日は何度でも挑める。
- **公平**: 毎日の挑戦は、**連続記録や逃したときの罰をつけない**こと。「今日の記録」があるだけで十分です。

## 第2幕 衝突 ― 3つの論争

### 論争1 難しくすると、しんどい人を置いていかないか

- **灯（傍聴）**: 疲れている日に、提灯が消えていくのはつらいかもしれません。
- **早瀬**: だから、単品の演目は**命なし**のまま残します。百鬼夜行は「挑戦したい日」の遊び。
- **宮城**: 難しさは、遊ぶ人が選べるのが一番です。
- **結論**: 単品の演目（妖怪当て・いまひろい・事実か考えか）は命なし。百鬼夜行だけに提灯。段位は選べる。

### 論争2 ローグライトは、のめり込みを生まないか

- **公平（倫理）**: 「もう一回」の力が強い仕組みです。課金やガチャはないとはいえ、夜中に何十回も遊ぶ形は避けたい。
- **霧島**: 一夜は**4〜5分**で終わる長さにします。
- **公平**: 続けて3回遊んだら、一度だけ「**ひと休みしませんか**」と声をかけてください。止めはしない。気づくきっかけだけ。
- **結論**: 一夜は短く。3回続けたら、ひと休みの声かけ（一度だけ）。連続記録なし。芸の札は遊びの中だけのもので、現実の価値はない。

### 論争3 新しい問題の種類は、CBTとして正しいか

- **森田（傍聴）**: 「言い直し」の問題で、ポジティブすぎる選択肢を「まちがい」とするのは賛成です。CBTのゴールはポジティブ思考ではなく、現実に合った考えです。まちがえたときに、その理由を必ず見せてください。
- **千石**: 「事実か考えか」は、「みんな」「きっと」「どうせ」が入っていたら考え、というだけで当たらないように、事実のほうにも感情のこもった文を混ぜます。
- **結論**: 言い直し問題は「バランス」「押しつけ」「ボケのまま」の三択で、まちがえたら理由を表示。事実の文にも、身近で感情の動く出来事を入れる。

## 設計原則（追加の5箇条）

31. **判断のない簡単さは、飽きる。**（色や消去法で当たらないようにする）
32. **ゲームが、体で教える。**（つかむと増える、長押しで味わう）
33. **難しさは選べる。命があるのは挑戦の場だけ。**
34. **毎回ちがう。でも一夜は短く。**
35. **見破られた妖怪は、お辞儀をして帰る。**（退治しない）

## 技法との対応表（今回の追加分）

| ゲームでの体験 | ねらい | 考え方の出どころ |
|---|---|---|
| まぎらわしい妖怪の見分け | 認知の歪みの細かな区別 | CBTの心理教育 |
| 言い直しはどれ？ | 現実に合った考えと、ポジティブの押しつけの区別 | 認知再構成法 |
| 事実か考えか | 出来事と解釈を分ける | CBTの基本（状況と自動思考の区別） |
| 増える考え | 考えに関わるほど増える（反すう） | メタ認知療法、ACT |
| 福の泡を長押し | よい体験を少し長くとどめる | 味わい（セイバリング） |
| 体のざわざわを拾う | 不安の体の感覚も「いま」 | マインドフルネス |
| 苦手克服・見分けの星 | 苦手を集中して練習し、上達を見える化 | 学習科学（想起練習・間隔をあけた練習） |
| 段位・百鬼夜行 | 難しすぎず簡単すぎない状態を選べる | フロー理論、自己決定理論（有能感・自律性） |
