# ココロ寄席 第八回設計会議 ― 書きやすく、やりたくなる

> 第八回の議題は、ユーザーからの六つの声です。
> 1. 「福日記が書きにくい。『丸いもの』を書いて何になるの？と感じる。感謝・よかったこと・ラッキーだったことなど、**書ける範囲が広いポジティブな切り取り方**を選択肢に」
> 2. 「エレベーター呼吸は、**ネドじゅんの提唱するやり方を踏襲**して」
> 3. 「いまの感じを選んだり、**数字で入れるのが面倒な時**がある。幸福に必要なプロセスなら残して」
> 4. 「大喜利を、**幸福のトレーニング**にもしたい。今の構成でよいか、もっと良いものを」
> 5. 「**飽きない設計**を、さらに深めて」
> 6. 「行動おみくじは、**出たものを強制的にやる**くらいのテンションが面白い。行動からブロックを外して、幸福に」
>
> 今回は、それぞれの声に正面から答えられるプロフェッショナルを集めました。登場人物は、役割を明確にするための**架空の人物**です。

## 第1幕 福日記 ―「丸いもの」を書いて、何になるの？

- **筆谷（ジャーナリング）**: 正直な、いい指摘です。「丸いもの」は、注意を外に向ける練習としては意味がある。でも**日記の手がかり**としては、よいことと結びついていない。書いた人が「これで何が変わるの？」と思った時点で、手がかりとしては失敗です。
- **三好（ポジティブ心理学）**: 幸福の研究で効果が確かめられてきたのは、「よかったこと」「感謝」「親切」「味わい」です。どれも**意味のある切り口**です。「赤いもの」は、そこに入っていません。
- **筆谷**: 書きやすさの鍵は「切り口の広さ」と「自分で選べること」。同じ一日でも、「よかったこと」では何も出てこないのに、「ラッキーだったこと」なら「信号がちょうど青だった」が出てくる。**切り口を変えると、思い出せる記憶が変わる**んです。
- **灯**: 3行それぞれに、切り口を選べたらうれしいです。今日は感謝が書けそう、とか。
- **結論**: 「レンズ」を、9つの**ポジティブな切り口**に置きかえる。各行で自由に選べる。

| 切り口 | 例 | ねらい |
|---|---|---|
| よかったこと | なんでもOK | 三つのよいこと |
| ありがとう | お店の人がていねいだった | 感謝 |
| ラッキー | 信号がちょうど青だった | 小さな幸運に気づく |
| おいしい・気持ちいい | お風呂があたたかかった | 五感の味わい |
| ほっとした | 仕事がひと区切りついた | 安心の瞬間 |
| 笑った | 同僚の言いまちがい | おかしみ |
| できた | 洗い物をひとつ片づけた | 小さな達成 |
| やさしさ | 席をゆずってもらった | 親切（された・した） |
| 明日の楽しみ | 明日は好きなパンを買う | 希望・予期の喜び |

- **三好**: 朝のお題も、この切り口から出しましょう。「今日はラッキーさがしの日」。朝に切り口を決めておくと、一日のうちにそれが目に入りやすくなる。お題の意味が、ちゃんと夜の日記につながります。

## 第2幕 エレベーター呼吸 ― 原典にそろえる

- **息吹（呼吸法）**: これまでの版は「一階ずつ下りて、ハラ階でとどまる」でした。ネドじゅんさんの紹介しているやり方とは違います。公開されている紹介（本人の動画「オカン・メソッド基礎編２『エレベーターの呼吸』」、実践者の解説）をまとめると、こうです。
  1. **のどのあたりに、まるい「床」**をイメージする
  2. **息を吸いながら、その床をおなかの底まで下ろす**。下りるにつれて、床はおなかの形にそって自然に広がる
  3. **吐きながら、のどまで上げる**
  4. これを**何度もくり返す**（向きは逆でもよい、とされている）
  5. コツは、**速く動かさず、おなかの内側の壁をズリズリとこするように、ゆっくりリアルに**
  6. のどと下腹に手をそえると、感じをつかみやすい
  7. **質より量**。くり返すほどなじむ
- **息吹**: 人の名前を借りてやり方を紹介するなら、原典にそろえるのが礼儀です。そして、くわしくは本人の本・動画で確かめてもらう一文を残す。
- **宴（ライブ運営）**: 「質より量」なら、**通算の往復数**を数えましょう。「通算300往復」。それ自体が、続けたくなる目印になります。
- **結論**: のどの床が、吸う息で下り、吐く息で上がる往復の形に作り直す。向きは切りかえ可能。終わったら「もう10往復」。通算の往復数を表示。

## 第3幕 数字の記録は、幸福に必要か

- **寸田（心理測定）**: 結論から言うと、**毎回は必要ありません**。数字の役目は三つです。①前後の変化に気づいて「効いた」と実感する、②自分に合う演目を見つける、③行動の予想と実際を比べる（行動実験）。どれも価値はありますが、**練習そのものの効き目は、数字がなくても変わりません**。
- **軽井（行動デザイン）**: めんどうは、習慣の最大の敵です。スライダーで「60か65か」を考えるのは、小さいけれど確かな負担。**選択肢を5段階のワンタップにする**だけで、迷いはほぼ消えます。
- **三好**: ただし、**気持ちに名前をつけること**は残したい。「不安」と名前をつけるだけで、気持ちが少し扱いやすくなる（感情のラベリング）。これはワンタップです。
- **灯**: 疲れた日は、数字を考える元気がないんです。「なし」も選べるとうれしい。
- **動（行動活性化）**: おみくじの「予想と実際」だけは、行動活性化の学びの中心です。「やる前は低く見積もっていたのに、やったら上がった」。これが、次の一歩の燃料になる。数字がなくても、「思ったより良かった？」と聞けば学びは残せます。
- **結論**: 記録のしかたを三つから選べるようにする（楽屋と、漫才の最初の画面で切りかえ）。
  - **ワンタップ**（はじめの設定）：5段階のことばから選ぶ
  - **細かく**：これまでのスライダー
  - **数字なし**：数字はとばす。最後に「軽くなった？」「思ったより良かった？」だけ、ことばで聞く
  - 気持ちの名前（不安・落ちこみ……）は、どのモードでも残す

## 第4幕 大喜利を「幸福の筋トレ」に

- **鹿野（注意訓練）**: いまの大喜利は、「歪みを見分ける」「事実と考えを分ける」「いまに戻る」を鍛えています。いい構成です。足りないのは、**よいものに注意が向く**練習です。
- **鹿野**: 有名な研究があります。たくさんの**しかめっ面の中から、ひとつの笑顔をすばやく見つける**ゲームを続けた人たちは、拒絶に注意が引っぱられにくくなり、仕事のストレスがやわらいだ、という報告です。人は不安なとき、怒った顔や冷たい顔に目が行く。それを、**受け入れてくれる顔に目が行く**ように練習するんです。
- **宴（ライブ運営）**: 寄席なら、それは「**客席の笑顔さがし**」ですね。高座から客席を見わたして、ウケている顔をさがす。芸人がいちばん欲しいものです。
- **三好**: 大喜利全体を「心の筋トレ」として見せましょう。どのゲームで、どの力がきたえられるか。
- **結論**:
  - 新しいゲーム「**客席の笑顔さがし**」（単品・百鬼夜行の演目）
  - 大喜利の入口に「**心の五力**」：見分ける力・言い直す力・分ける力・戻る力・見つける力。遊ぶほど力のレベルが上がる

| 力 | きたえるゲーム | 幸福とのつながり |
|---|---|---|
| 見分ける力 | 妖怪当て | 考え方のクセに気づく |
| 言い直す力 | 言い直し問題 | 現実に合った考えを選ぶ |
| 分ける力 | 事実か考えか | 出来事と解釈を分ける |
| 戻る力 | いまひろい | 考えから「いま」に戻る |
| 見つける力 | 笑顔さがし・福の泡 | よいものに注意を向ける |

## 第5幕 飽きない設計 ―「今日の三題噺」

- **宴（ライブ運営）**: 長く遊ばれるアプリには、①**毎日ちがう小さな目標**、②**成長の目盛り**、③**選ぶ楽しさ**があります。ココロ寄席には②と③はある。足りないのは①です。
- **宴**: ただし、連続記録（ストリーク）は使いません。途切れたときの罪悪感が、心のアプリでは毒になる。
- **結城（宮司）**: 落語には「**三題噺**」があります。客から三つのお題をもらって、その場で一席こしらえる。毎日三つのお題が出て、全部こなすと一席できあがる、というのはどうでしょう。
- **軽井**: お題は、ちがう演目から一つずつ。時間帯で変わるといい。朝ならおみくじ、夜なら福日記や呼吸。どれも**1〜3分で終わる**ものに。
- **結論**: 番組（ホーム）に「**今日の三題噺**」。日付で決まる三つのお題、終わったものに印、三つそろうと小さな噺ができあがる。翌日にはまた新しいお題。連続記録はつけない。

## 第6幕 行動おみくじ ―「出たら、やる」

- **結城（宮司）**: おみくじは本来、**神様からのお告げ**です。気に入らないから引き直す、というものではありません。凶が出たら、それを戒めとして受け取る。その**ゆずれなさ**が、おみくじの力です。
- **動（行動活性化）**: 行動活性化でいちばん難しいのは、「何をやるか決めること」と「始めること」。おみくじが決めてくれるなら、迷いが消えます。**選ばなくていい自由**です。そして「始める」には、**勢い**がいる。
- **軽井**: カウントダウンを入れましょう。「5・4・3・2・1、いざ！」。考える前に体を動かす。
- **灯**: でも、本当に無理な日もあります。
- **動**: そこで「**半分ルール**」です。引き直しはなし。代わりに、**最初の10秒だけやる**に縮めてよい。行動活性化でいう「段階的な課題」です。ゼロにはしない、でも小さくはしていい。
- **三好**: 新しい種類も足しましょう。「**勇気**」（後回しにしていたことに、最初の一歩だけ）と「**親切**」（だれかのための小さなこと）。小さな親切は、する側の幸福感も上げることが知られています。
- **結城**: 凶は「今日は休め」のままで。休むのも、お告げです。
- **結論**:
  - **おみくじの掟**：一、出たら、やる。二、無理なら半分（最初の10秒）でよい。三、やったら、自分をほめる。
  - 引き直しはなし。「半分にする」と「いざ！」（5秒のカウントダウン）
  - やってきたら「**達成**」の判子
  - 新しい種類「勇気」「親切」
  - どうしても無理な日の「今日は降りる」は、小さく残す（安全のため）
